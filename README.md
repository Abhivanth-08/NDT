# NDT-Based Crack/Defect Detection Device

# Description:
A device designed to detect cracks and defects in structures using Non-Destructive Testing (NDT) mechanisms. Provides accurate detection without damaging the target surface. Suitable for industrial inspections, civil infrastructure monitoring, and quality control.

# Features:

Detects cracks, defects, and surface anomalies

Portable and lightweight design

Uses imaging and sensor data for accurate predictions

Real-time data processing and alerts

AI-assisted defect recognition

# Technologies Used:

Raspberry Pi / Microcontroller

Python

NDT Mechanisms: Ultrasonic
